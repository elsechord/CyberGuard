# README and social artwork

The banners embed the approved CyberGuard / from Elsechord logo outlines without changing the symbol or wordmark. Logo typography license notices are included here. Banner captions use system fonts at render time; no system font files are redistributed.

- `../cyberguard-readme-en.png` and `../cyberguard-readme-zh.png`: 1600 × 800 README posters.
- `../cyberguard-social.png`: 1280 × 640 GitHub Social Preview upload asset.
- Corresponding SVGs are editable source artwork. Approved logo lettering remains outlined.

To use the social card, upload the PNG in the repository's Social preview setting. Keeping this file in the repository does not change that setting automatically. This documentation change does not publish or change repository settings.

The current observation-field artwork derives its contour lines from the approved animal path. It is a brand illustration, not a visualization of measured security data. Color adaptations preserve the approved logo geometry.

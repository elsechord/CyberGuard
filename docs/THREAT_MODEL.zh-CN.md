# 威胁模型

[English](THREAT_MODEL.md) · [中文文档导航](README.zh-CN.md)

## 保护对象与信任边界

保护对象包括模型及安全产品凭据、受限遥测与证据、人工批准权限、调查决定／动作历史／报告完整性，以及 AgentTeams 和业务系统的可用性。

边界包括：人和 Matrix／Element 的交互；AgentTeams 和 Worker 的产物；Higress 与 MCP／API 的凭据代理；只读调查与可变更处置之间独立的服务、token 和网络；外部安全产品返回的不可信数据；容器控制面与宿主机。Docker 运行时权限等价于很强的主机权限。

## 主要威胁与控制

| 威胁 | 控制措施 |
| --- | --- |
| 工具输出提示词注入 | 将输出当数据、结构化 schema、受限工具 |
| 幻觉根因 | 竞争假设、证据 ID、置信信息与独立复核 |
| 凭据外泄 | Higress 代理、角色秘密分离，不把秘密放进提示词／Matrix |
| 未授权响应 | 独立执行凭据与人工审批秘密；批准有有效期并绑定具体方案哈希 |
| 重复动作 | 必填幂等键、串行状态流转及本地执行状态约束；回滚后关闭原动作 |
| 影响范围过大 | 小型动作集合、具体目标、L0–L3 风险分级与恢复路径 |
| 审计篡改 | SHA256 链、每记录 HMAC-SHA256，支持卷外保留认证检查点 |
| 跨事件混淆 | 每个工具调用、证据和动作都带事件 ID |
| 无关动作造成误判恢复 | 用认证后的执行状态核对场景要求的 action/target，部分、错目标或已回滚集合不通过 |
| 边界来源伪装 | 防火墙／网关来源与密级服务端固定，策略证据与 NDR 流量关联 |
| 敏感数据泄漏 | 处理标签，大型／受限材料以引用保存 |
| 供应链风险 | 固定 AgentTeams 和 Python 依赖，限制镜像来源 |
| 容器逃逸／主机接管 | 非 root、只读文件系统、no-new-privileges、移除 capabilities 与专用主机 |

## 设计约束

1. L2 动作需要绑定精确提案哈希、仍有效的批准。
2. Agent 不取得人工审批秘密。
3. 规划和独立复核由不同 Worker 承担。
4. 重要主张引用 Evidence ID 或 Action ID。
5. 演练动作限定类型和目标、保持幂等；确定性比赛演示提供对应恢复路径。
6. 失败或不确定应回到调查／恢复处理，不默默结束事件。
7. 基础确定性场景的恢复记录要求通过认证只读通道核对完整动作／目标集合；真实实验另以实际探针核对效果。

这些是设计与具体实现应满足的约束，不表示仅凭提示词就能强制所有 Agent 遵守。远端厂商接口是否支持幂等、补偿或回滚需逐接口验证。

## 已知边界

基础场景使用确定性模拟数据，真实连接器来源还没有通用密码学认证。原生真实模型调查和无害进程实验的验证范围分别见运行记录。

本地 HMAC 记录可发现卷内容相对可信密钥／检查点的改写；生产级不可抵赖仍需要外部追加存储或非对称签名。Agent 遵循程度需对抗评测，提示词本身不是安全边界。Docker socket／proxy 权限需限制到专用主机和受控管理员。

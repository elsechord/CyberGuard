## 运行

本地私有连接配置和已有验证密钥位于 WSL root 的配置目录，不能提交到仓库。
该脚本使用既有验证部署；不是面向新用户的安装器。每次使用全新编号：

```sh
python3 deploy/investigation-service/validate-full-case.py --attempt 001
```

每轮独立源房间、独立有限预算账本，保留既有 Console 数据卷。默认二十分钟
截止；超时通过原生暂停接口取消。完成后关闭该轮模型预算。结果位于工作区
上级 `output/full-case/<attempt>/`，需要继续逐条审阅报告语义，脚本不会把
`completed` 自动等同于内容正确。模型调用量不等于货币费用，实际账单取决于
网关定价。

## 本轮发现

AgentTeams v1.2.3 在创建 Project 时，如果填写 `source_room_id` 或
`reply_route.target_session`，会先发送“项目已创建”的普通聊天通知。
这会在完整请求到达前唤醒 Leader。适配器现已取消创建时的聊天回执地址，
只用携带全部材料的一次正式消息触发调查；产物仍通过 Controller API 返回。
没有修改上游原生 Task 状态，也没有用模型代替调度接口。

### 修复：直接传递原始案件文件

Console 使用已配置的 Matrix 媒体 API 上传 `case.json`，不额外发送聊天通知。
文件包含原始材料、原始哈希和最终报告格式。Worker 使用现有 Matrix 身份，
通过 `case_packet.py fetch` 获取原始字节并验证哈希；不用模型转抄材料。
每项任务的说明开头必须保留文件 URI 和任务编号。复核 Worker 可在提交前用
`case_packet.py check` 检查格式和逐字引用；Console 的最终校验仍然保留。

这是同一受信 AgentTeams 部署内的传输方案。Matrix 媒体 URI 不是独立的
租户授权边界；不要将其当成跨租户私有对象存储。当前案件包仍限 60 KiB。
部署时须将该 helper 安装到所有参与 Worker（安装脚本已包含），而非仅升级
Console 镜像。实际媒体上传、下载和哈希预检通过，不消耗模型请求。
